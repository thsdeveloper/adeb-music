## Responsividade

### Desktop (>1024px)
- Navbar horizontal completo
- Hero full screen
- Grid de artistas: 3 colunas
- Grid de lançamentos: 4 colunas
- Grid de serviços: 4 colunas
- Grid de bastidores: 4 colunas
- Grid de stats: 4 colunas
- Footer: 4 colunas

### Tablet (768px - 1024px)
- Navbar horizontal
- Grid de artistas: 2 colunas
- Grid de lançamentos: 2 colunas
- Grid de serviços: 2 colunas
- Grid de bastidores: 4 colunas (mantém)
- Grid de stats: 2 colunas
- Footer: 2 colunas

### Mobile (<768px)
- Navbar com menu hambúrguer
- Hero mantém proporção
- Grid de artistas: 1 coluna
- Grid de lançamentos: 1 coluna
- Grid de serviços: 1 coluna
- Grid de bastidores: 2 colunas
- Grid de stats: 1 coluna
- Footer: 1 coluna (stack)
- Formulário: campos empilhados

## Animações e Interações

### Hero Section
- ✨ Fade in e slide up no carregamento
- 🌊 Parallax effect no scroll
- ⚡ Hover effect nos botões (scale + shadow)

### Cards (Artistas, Lançamentos, Serviços)
- 🎯 Hover: scale(1.05)
- ✨ Hover: border dourado
- 💡 Hover: shadow com cor temática
- 🎨 Transições suaves (300ms)

### Estatísticas
- 🔢 Animação de contagem ao scroll
- 👁️ Intersection Observer
- ⚡ 2 segundos de duração

### Formulário
- ✅ Validação de campos
- 💬 Feedback visual
- 🎉 Mensagem de sucesso

### Navbar
- 🎯 Fixa no topo ao scroll
- 🌫️ Backdrop blur effect
- 📱 Menu mobile responsivo

## Acessibilidade

- ✅ Contraste de cores adequado
- ✅ Labels em formulários
- ✅ Alt text em imagens
- ✅ Navegação por teclado
- ✅ ARIA labels em botões
- ✅ Semantic HTML

## Performance

- ⚡ Static Generation (SSG)
- 🚀 Tailwind CSS otimizado
- 📦 Code splitting automático
- 🎨 CSS-in-JS inline para animações
- 🔄 Lazy loading pronto para imagens

---

**Visual Hierarchy**
A estrutura visual segue uma hierarquia clara:
1. Hero captura atenção
2. Sobre estabelece confiança
3. Artistas mostram o portfólio
4. Lançamentos provam atividade
5. Serviços apresentam valor
6. Bastidores criam conexão
7. Stats validam impacto
8. Contato facilita ação
9. Footer oferece navegação

Cada seção tem seu propósito no funil de conversão.
